## Tracking rules

- Keep stable IDs. Add new findings only after checking for duplicates here.
- An unchecked box means work or verification remains. Statuses: **Open**, **In progress**, **Needs verification**, **Verified fixed**, **Deferred**, **Not a bug**.
- Check a box only after reproducing the original failure and verifying the correction. Record the fix commit (or explicitly say uncommitted), regression command/result, and verification date. A source edit or passing build alone is not proof.
- Findings in the first table are assigned to the other ongoing fix effort. Do not duplicate that work. Its current working-tree edits have not been independently verified by this audit.
- Source links are relative to this app repository; line numbers can move. P1 = high priority; P2 = normal priority. Optimization entries are opportunities, not measured speedup claims.
